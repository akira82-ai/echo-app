## ✨ 特性

- 🎯 **全自动记录** — 监听剪贴板本身（非按键），右键、剪切、拖拽、App 内按钮统统不漏。
- 🔢 **一个输入框，智能识别三种意图** — 输 `1`–`5` 直达当前页；输 `6+` 或文字即搜索；空输则用方向键浏览。
- ✦ **空状态也可呼出** — 没有历史记录时，`⌘\` 仍能打开面板并给出下一步引导。
- 🖼️ **三类内容** — 文本（保留原格式，支持 Markdown 粘贴）、图片（截图或复制图片）和 Finder 中复制的文件。
- 📝 **Markdown 粘贴** — 按 `⌥↵` 将复制的富文本转为 Markdown，支持标题、链接、列表、代码块和简单表格；多选后可按选择顺序合并粘贴。转换在本地完成，结果缓存在内存中。
- ⌨️ **全局热键** — `⌘\` 呼出 Spotlight 风格面板，任意 App 中可用。
- ✨ **轻量入场动效** — 面板与首屏条目自然出现，尊重 macOS「减少动态效果」设置。
- 🎯 **选中反馈更连贯** — 键盘移动时高亮背景平滑跟随，不打断连续选择；多选时只突出已选条目。
- 🌙 **聚焦内容的明暗面板** — 紧凑搜索区、固定五行、轻量类型标识与明确的选中侧标，让找、认、选、贴更清楚。有来源时保留 App 名称或浏览器网址副行；底栏显示当前页和粘贴方式。
- 🧩 **文本多选粘贴** — 按住 `⌘` 后，点击或按 `⌘↵` 选择最多 5 条文本；松开后按 `↵`，按选择顺序合并粘贴。
- 🧹 **快速整理** — 按 `⌥⌫` 删除当前条目，不占用搜索框的退格键。
- ⌘ **完整快捷键说明页** — 按 `Tab` 或点击帮助，在双栏分组中查看通用操作、粘贴与来源、多选合并的完整说明。再按 `Tab` 返回历史，`Esc` 关闭面板。
- 📤 **自动粘贴** — 选中后自动粘到当前 App 光标处，无需手动 `⌘V`。
- 🏷️ **复制来源** — 每 0.1 秒检测剪贴板变化，普通 App 显示检测时的应用名字；浏览器显示「浏览器名字 · 页面地址」。获取不到来源时不显示；来源是前台应用的尽力推断，并非系统提供的确切写入者身份。
- 🔗 **找回浏览器页面** — 支持 Safari、Chrome、Edge 和 Ego；文本、图片及文件条目均可关联观察到的页面，右键条目或按 `⌃↵` 打开。地址采集需要辅助功能权限；未适配的浏览器不显示来源。应用名字、标题和网址只保存在内存中。
- 🌐 **跟随系统语言** — 界面支持简体中文、English、日本語，自动跟随 macOS 系统语言。
- 🔒 **零权限优先** — 基础剪贴板记录与热键无需权限；自动粘贴与浏览器页面找回使用可选的辅助功能权限。
- ♻️ **本地优先** — 历史纯内存，退出或重启后清空。已有勋章统计保留在本地，主面板不再显示勋章入口，数据不出本机。

## 🚀 快速上手

### 方式一：下载源码并编译

```bash
# 编译、打包、签名，并生成 dist/Echo.app 与 dist/Echo.dmg
./build-app.sh
open dist/Echo.app
```

`build-app.sh` 会自动使用本机的 `Echo Self-Sign` 证书。后续优化后重复执行即可，不需要手工重新签名；请始终启动 `dist/Echo.app`，不要直接运行 `.build/.../Echo`。

### 方式二：下载 Release

前往 [Releases](https://github.com/akira82-ai/echo-app/releases)，下载最新 `2.9.0` 版本（build 16）的 `Echo.dmg`。打开 DMG 后，将 Echo 拖进「应用程序」即可。

当前 Release 是本机开发验证包，使用 `Echo Self-Sign` 自签名，不是 Apple Developer ID 签名和 notarization 的正式发行包。因此，首次打开时 macOS 可能提示「无法验证开发者」或拦截应用：

1. 在 Finder 中找到 Echo，按住 Control 点击，选择「打开」，再确认一次「打开」。
2. 如果仍被拦截，打开「系统设置 → 隐私与安全性」，在安全提示旁点击「仍要打开」，然后重新启动 Echo。

首次使用「自动粘贴」时，系统会弹出辅助功能授权引导。授权后选中条目即可自动粘贴；不授权也能用，只是需要回到目标 App 手动按 `⌘V`。

```
① 正常复制（⌘C / 右键 / 拖拽）     → Echo 自动记录进历史
② 按 ⌘\                            → 弹出历史选择面板
③ 选一条（1–5 / 6+ 搜索 / 方向键）  → 自动粘到当前光标
   ⌥↵ 粘贴 Markdown，默认回车保留原格式
④ 按住 ⌘，选择最多 5 条文本；松开 ⌘ 后按 ↵，按顺序合并粘贴
⑤ 按 ⌥⌫ 删除当前条目，连续操作可逐条整理
⑥ 按 Tab 查看快捷键说明，再按 Tab 返回历史列表，Esc 关闭面板
```

**系统要求：** macOS 13 Ventura 及以上。

### Markdown 粘贴

复制入历史后，Echo 根据保存的 HTML 或 RTF／RTFD 文本，在本地生成 Markdown 并缓存在内存中，不改系统剪贴板，列表预览也保持不变。按 `⌥↵` 粘贴结果；尚未转换完成时会等待，等待期间可按 `Esc` 取消。纯文本原样输出。

支持常见文本结构和简单表格；合并单元格、嵌套表格会明确拒绝，图片附件不保证支持。转换失败会提示，且不会替换剪贴板，可按 `↵` 改用原格式粘贴。多选后 `⌥↵` 按选择顺序用空行合并 Markdown，普通回车仍合并纯文本。

**2.9.0 快捷键变化：** `⌥↵` 从原来的纯文本粘贴改为 Markdown 粘贴。

### 自动粘贴排查

如果选中历史项后没有自动粘贴，先确认正在运行的是 `dist/Echo.app`，然后在「系统设置 → 隐私与安全性 → 辅助功能」中确认 Echo 已授权，并检查设置页的「启用自动粘贴」开关。即使没有权限，Echo 仍会把内容写回剪贴板，可以回到目标 App 手动按 `⌘V`。
