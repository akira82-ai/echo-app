## 特性

- **复制过，随手找回** — 文本、图片、Finder 文件自动收录。按下 `⌘\`，搜一下、选一条，接着用。
- **摘录到笔记，少一步整理** — 将复制的富文本直接粘贴为 Markdown，保留标题、链接、列表等常见结构，转换全在本地完成。
- **多条素材，一次粘贴** — 最多选取 5 条文本，按你的顺序合并粘贴。整理摘录、拼接资料，少几次来回切换。
- **随手一算，接着工作** — 输入 `!` 开始计算，回车用上结果。从简单算式到常用函数，无需另开计算器。
- **有疑问，随手一问** — 输入 `@`，在当前面板里向 DeepSeek 提问；需要时由模型搜索、读取网页，回答边生成边呈现。需自备 API Key。
- **让问答更像你的助手** — 在「模型设置」中编辑系统提示词，随时恢复 Echo 默认值，定制每次新问答的语气与规则。
- **长问题，也有足够空间** — 快速搜索时保持紧凑，输入长内容或多行问题时在原位向下展开，不改变面板外框。按 `⇧↵` 换行，按 `Esc` 收起。
- **找回内容，也找回出处** — 查看复制内容的来源 App 或网页；识别到网址时，一步回到原页面，继续阅读和查证。
- **原生体验，融入 Mac** — 明暗主题随系统切换，支持「减少动态效果」与中、英、日三种语言。需要时呼出，用完即收起。

## 常见问题

**Echo 是什么？一句话说。**
Mac 菜单栏里的极简智能剪贴板：找回复制内容、粘贴 Markdown、算一下、问一下，一个面板全干。免费开源（MIT），无订阅、无内购、无账号。

**已经在用 Maccy / Paste / Raycast，还值得试试 Echo 吗？**
看你缺哪一步：
- 喜欢 Maccy 的极简，但还想要 Markdown 粘贴、计算和问答 → 试试 Echo；
- 需要 Paste 那样的持久历史库 → 它更合适。Echo 选了另一个方向：剪贴板是暂存区，重启即清、零残留；
- 重度 Raycast 用户 → 留在 Raycast 挺好。Echo 是给「只想贴段文字、顺手算一下问一下，不想为此装一个启动器」的人。

**我的剪贴板数据会被上传吗？**
不会。历史与缓存全部留在本机，重启即清空（细节见下方「隐私与权限」）。「问一下」会将当次问题和你保存的系统提示词发送给 DeepSeek；剪贴板历史不会被自动上传。

**「问一下」会把我的剪贴板历史发给 DeepSeek 吗？**
不会。只有你当次输入的问题、以及你手动粘贴进问题的内容会发送；剪贴板历史不会被自动附带，各问题相互独立、不带上文。需要查证时，模型生成的搜索词和网页地址会发给 DeepSeek 的搜索服务。

**为什么「问一下」要我自己填 API Key？**
Echo 不做中转、不经手你的额度：Key 存在 macOS 钥匙串，请求从你的机器直连 DeepSeek，用量和费用完全由你掌控。

**Markdown 粘贴有什么限制？**
保留标题、链接、列表等常见结构；合并/嵌套表格与图片附件暂不完整支持。转换失败时剪贴板保持原样，回车仍可粘贴原格式。

**为什么启动时 macOS 提示「无法打开」？**
Echo 使用自签名，未经 Apple 公证。先尝试打开，再到「系统设置 → 隐私与安全性」点「仍要打开」并确认即可（见「安装」）。介意的话，也可以用源码自行构建——这也是开源的意义。

**自动粘贴为什么要「辅助功能」权限？**
自动写回目标 App 需要该权限。不授权也能正常用：回车复制后，到目标 App 按 `⌘V`（见「使用」）。基础的剪贴板记录和 `⌘\` 全局快捷键不需要任何权限。

## 使用

正常复制，按 `⌘\` 呼出面板，选择条目并回车。自动粘贴需要辅助功能权限；未授权时，回到目标 App 按 `⌘V` 即可。

输入框沿用 Mac 常用编辑快捷键：`⌘A` 全选、`⌘V` 粘贴纯文本，`⌘X` / `⌘C` 剪切或复制选中文字；有可撤销的编辑时，使用 `⌘Z` / `⇧⌘Z` 撤销或重做。剪贴板搜索、计算和问答输入均可使用；`Ctrl+A` 保留 macOS 默认文本编辑行为。

| 面板内操作 | 作用 |
| --- | --- |
| 输入 `1`–`5` 后回车 | 粘贴当前页对应条目 |
| 输入关键词或 `6+` 的数字 | 搜索历史 |
| 方向键 | 浏览历史 |
| `↵` / `⌥↵` | 原格式 / Markdown 粘贴 |
| 按住 `⌘`，点击或按 `⌘↵` | 将文本加入或移出多选 |
| 松开 `⌘`，按 `↵` / `⌥↵` | 将多选合并为纯文本 / Markdown 粘贴 |
| `⌥⌫` | 删除当前条目 |
| 右键 → 打开来源页面，或 `⌃↵` | 有浏览器页面来源时打开该页面 |
| `Tab` | 切换剪贴板快捷键说明 |
| `Esc` | 关闭面板，或取消 Markdown 等待 |

### Markdown 粘贴

按 `⌥↵` 粘贴 Markdown，普通回车保留原格式；纯文本原样输出。复制后在本地预先转换，不改写剪贴板或列表预览。

合并单元格、嵌套表格和图片附件尚未完整支持。转换失败不会替换剪贴板，可按回车改用原格式。

### 即时计算

输入 `! (128+36)/4` 即可计算。支持中英文括号、四则运算、`sqrt(81)`、`pow(2,3)` 等；`%` 表示取余。

回车粘贴结果并关闭面板；未选中文字时，`⌘C` 复制结果并保留面板。在空输入框键入 `!` 或 `！` 切换为计算模式，`@` 切换为问答模式；触发符号不进入正文。删完算式或问题后再按一次退格恢复搜索；粘贴内容保持原文。结果为浮点计算，最多 15 位有效数字，不适用于精确十进制结算。

### 临时问答

「设置 → 模型设置」可编辑系统提示词并恢复默认，保存后从下一次提问生效，不影响正在进行的请求。自定义提示词保存在本地，提问时随请求发送给模型，升级不会覆盖；恢复默认并保存后使用应用自带的最新默认值。日期、时区和实际工具能力由程序动态附加。默认回答结论先行、简明直接，适配单轮问答及面板排版。

在「设置 → 模型设置」中保存 **DeepSeek API Key**。接口地址固定为 `https://api.deepseek.com/v1`，模型固定为 `deepseek-chat`；Key 保存在 macOS 钥匙串。

在空输入框键入 `@` 切换左侧模式图标，再输入问题并回车；触发符号不进入正文或发送内容。未选中文字时，`⌘C` 复制完整回答。修改输入会清空回答并取消请求，`Esc` 关闭并取消；删完问题后再按一次退格返回搜索。重新呼出面板会恢复内存中的上次问题及问答模式，但不保留回答，也不会自动重发。

模型可使用同一个 Key 调用 [DeepSeek 搜索与网页读取](https://api-docs.deepseek.com/zh-cn/guides/search)，无需另开开关。系统要求回答引用来源，重要事实和链接仍需核对。各问题独立，不自动附带此前对话或剪贴板历史。

## 安装

需要 **macOS 13 Ventura 及以上**。当前预编译包适用于 **Apple Silicon**；Intel Mac 需从源码构建。

### 下载 Release

在最新 [Release](https://github.com/akira82-ai/echo-app/releases/latest) 下载 `Echo.dmg`，打开后将 Echo 拖入「应用程序」。也可下载 ZIP。

当前版本：**2.14.2（build 26）**。

Release 使用 `Echo Self-Sign` 自签名，未经 Apple Developer ID 签名或公证。首次启动若被 macOS 拦截，尝试打开后，前往「系统设置 → 隐私与安全性」，点击「仍要打开」并确认。

### 下载源码并编译

先安装带有 **Swift 6.2 及以上**的 Xcode 或 Apple Command Line Tools（当前依赖要求），再执行：

```bash
git clone https://github.com/akira82-ai/echo-app.git
cd echo-app
./build-app.sh
open dist/Echo.app
```

脚本会编译并打包应用；本机有 `Echo Self-Sign` 证书时使用该证书，否则使用临时签名（ad-hoc）。请启动 `dist/Echo.app`，以正确加载资源并处理权限。首次构建需要下载依赖。

## 隐私与权限

- **本地剪贴板数据：** 历史与 Markdown 缓存不会在重启 Echo 后恢复。图片原图会缓存到 `~/Library/Caches/Echo/images/`，条目删除或淘汰时清理对应图片，启动时清空图片缓存。设置和已有使用统计保留在本地。
- **可选的辅助功能权限：** 基础记录与全局热键无需权限；自动粘贴和浏览器网址采集需要辅助功能权限。来源识别可能缺失或不准确。
- **DeepSeek 请求：** 临时问答会将输入内容、保存的系统提示词、模型生成的搜索词和网页地址发送至 DeepSeek，并将网页结果交给模型。手动粘贴到问题中的内容也会发送。服务商可能保存请求，聊天和联网调用可能产生费用。

自动粘贴失效时，请在「系统设置 → 隐私与安全性 → 辅助功能」中授权 Echo，并检查 Echo 设置中的「启用自动粘贴」。也可以手动按 `⌘V` 粘贴。
