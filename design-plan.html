03 · KEY TECH

四个关键技术点

每个点对应一个核心机制。把监听对象从「按键」换成「剪贴板本身」是本次重构的范式转变。

⏱️

changeCount 轮询

替代 CGEventTap 按键监听

用 0.5 秒定时器查 NSPasteboard.general.changeCount。这个计数器在剪贴板每次被修改时自增,任何来源(右键、剪切、拖拽、快捷键)都覆盖。

NSPasteboard.general.changeCount
💡 0.5s 延迟肉眼几乎无感,换来的是覆盖全部复制来源 + 零权限。这是 Maccy/Flycut/Paste 等所有同类工具的通用方案。
⌨️

RegisterEventHotKey

Carbon 公开 API,无需权限

注册系统级全局热键。比 CGEventTap 更稳定(不会被系统禁用),且完全不需要辅助功能权限。

RegisterEventHotKey(42, cmdKey, ...)
// 42 = "\" 键码
💡 默认 ⌘\。⌘V 被系统占用、⌘C 被复制占用,都不能用;⌘\ 是左手区两键组合,系统几乎不占用。
🖼️

图片三态处理

原图落盘 · 缩略图内存 · SHA256 去重

50 张截图原图可能几百 MB,内存扛不住。原图 PNG 落临时磁盘,内存只持 128px 缩略图,粘贴时才读回原图。

disk: {uuid}.png · mem: thumbnail · key: SHA256
⚠️ 图片分两种来源要区分:浏览器/截图复制是像素数据(.tiff);Finder 复制 .png 文件是文件路径(.file-url)。后者当文件处理,几乎不占空间。
📤

AX 权限降级粘贴

自动模拟 ⌘V,无权限则只写剪贴板

选中条目后:① 按类型写回 NSPasteboard;② 若有 AX 权限,用 CGEvent 模拟按 ⌘V 自动粘到目标 App;③ 无权限则静默跳过模拟,菜单栏提示。

AXIsProcessTrusted() ? simulateCmdV() : silent
💡 这是整个 App 唯一依赖 AX 权限的功能。关掉"自动粘贴"开关后,App 完全零权限运行——这是相对旧版最大的体验提升。
🔑 核心范式转变:监听对象从「按键」(CGEventTap,需 AX 权限)换成「剪贴板本身」(changeCount 轮询,零权限)。这是 Maccy / Flycut / Paste 等所有同类工具的标准做法——覆盖全部复制来源,稳定不被系统禁用。
04 · CONTENT MATRIX

三类内容的处理矩阵

文本、图片、文件三类型,在读取/存储/去重/粘贴/UI 各环节的处理方式对照。读取顺序很关键:先判文件 URL,再判图片数据,最后降级文本——避免把图片文件误当像素抓。

类型 读取 API 存储 去重 key 粘贴写回 UI 显示
📝纯文本 string(forType:.string)
自动丢弃 RTF/HTML		 内存字符串
占用极小		 text:+内容 writeObjects([str]) 截断的文字预览
🖼️图片 readObjects([NSImage])
仅当含 .tiff/.png		 原图 PNG 落盘 +
内存缩略图 ~128px		 image:+SHA256 NSImage(contentsOf:)
→ writeObjects([img])		 缩略图 + 尺寸标注
📎文件 readObjects([NSURL])
优先于图片判断		 URL 字符串(内存)
占用极小		 files:+路径排序 writeObjects([url]) 文件名 + 类型图标
📎 文件类型的「零拷贝」机制:存储和写回剪贴板都只放 NSURL 路径指针,从不读取文件数据 → 历史项几乎零内存成本,粘贴瞬时。真正的"复制"动作由接收方 App 在粘贴时自己执行(Finder 拷文件 / Word 嵌入 / 微信上传)。
💬 微信对话框的特殊行为: · 粘 .png/.jpg 图片文件 → 当图片消息发送(直接显示图,非文件附件) · 粘 .pdf/.zip/.docx 等 → 当文件消息发送(显示文件卡片) ⚠️ 代价:源文件被删/移动后路径失效,粘贴报错。这是「不存副本」换来的取舍——剪贴板历史不做文件备份。
⚠️ 图片粘贴的已知限制:纯文本编辑器(终端、Sublime、VS Code 普通模式)不接受图片粘贴,会静默失败。这是目标 App 的能力问题,不报错——用户自然会换支持图片的地方粘。富文本场景(飞书文档/Word/Notes/微信)完全正常。

06 · INTERACTION

三种选择方式

面板呼出后,同一输入框智能识别三种意图:纯数字当编号、文字当搜索、什么都不输则方向键浏览。点击下方标签查看每种方式的完整流程。

1

按 ⌘\ 呼出面板

任何 App 中,光标已在某输入位置。面板浮现在屏幕中央,输入框自动聚焦。

2

输入纯数字(如 35)

面板实时判断:输入是纯数字且 ≤ 列表长度 → 视为「编号直达」;输入框右侧显示"→ 直达第 35 条"提示,列表自动滚动定位到该项高亮。

输入: 35 → 识别为编号 · 高亮第 35 条「订单号 #20260805-001」
3

按回车 → 粘贴并关闭

面板关闭 → 短延迟 80ms(等面板释放焦点,目标 App 重新前置)→ Paster 把内容写回剪贴板 → 模拟 ⌘V。

回车 → 面板关闭 → 写剪贴板 → 模拟 ⌘V → 「订单号 #20260805-001」已粘到光标处 ✅
1

按 ⌘\ 呼出面板

面板浮现,输入框聚焦。

2

输入文字(如「订单」)

输入含非数字字符 → 视为「搜索词」。对文本/文件条目做大小写不敏感子串匹配;图片条目不参与搜索,但仍保留显示。结果实时过滤。

输入: 订单 → 过滤出含「订单」的 2 条 · 其余隐藏
